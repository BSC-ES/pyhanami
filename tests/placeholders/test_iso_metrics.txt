# Test Plan: ISO metrics functions (all functions in utils/iso_metrics.py)

## Purpose
Verify that the ISO metrics functions correctly process and analyze TOA outgoing longwave radiation (OLR) data, including 
EEOF analysis, PC computation, event frequency calculation, and skill score evaluation.

## Inputs to test
- Normal case:
    - OLR xarray DataArray with time, lat, lon dimensions
    - Complete temporal coverage for both winter and summer seasons
- Edge cases:
    - Different lag values, number of modes, EEOF parameters or latitude range
    - Different time periods between model and observations
    - Missing data in specific seasons/regions
- Invalid inputs:
    - Wrong data type (not xarray.DataArray)
    - Missing or incorrect dimensions
    - Invalid coordinate values
    - Inconsistent temporal resolution

## Expected behaviour
- For valid inputs:
    - EEOF analysis returns correct number of modes and proper spatial patterns
    - PCs show expected phase relationships
    - Event frequencies match expected seasonal cycle
    - TSS components (correlation, std ratio) in [0,1] range
- For edge cases:
    - Handle different longitude conventions
    - Manage missing values without crashing
    - Adjust for different temporal coverages
- For invalid inputs:
    - Function should fail with meaningful error messages
