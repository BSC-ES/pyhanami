## What is pyhanami?

_pyhanami_ is a Python package that provides tools for:
1. Generating diagnostic visualizations
2. Evaluating the replicability of ESMs
3. Assessing the scientific skill of ESMs

For quick start instructions, see the [README](README.md). This Wiki provides in-depth documentation and advanced usage information.
